# trysystem_v1

個別指導塾の運用を想定した基幹システムです。
生徒・講師のデータベースを中心に、授業管理や講師割り当てなど、日々の実務をWebアプリ上で扱うことを目的にしています。

## Features

- 生徒データの登録・管理
- 講師データの登録・管理
- 授業予定の作成・確認
- 講師ごとの週間スケジュール確認
- 授業の振替・担当講師変更
- CSV / Excelからの初期データ取り込み

## Tech Stack

- Python
- FastAPI
- SQLite
- pandas

## Data Policy

このリポジトリには、実際の生徒・講師データ、授業リスト、SQLite DB、CSV、Excelファイルは含めていません。
公開用としてアプリケーションコードのみを管理し、個人情報を含む運用データはローカル環境で扱う前提です。

## Notes

開発途中の検証用プロジェクトです。
実運用に近い業務フローを想定しながら、データベース設計、API設計、授業管理機能を段階的に実装しています。
